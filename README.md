# Chilamban House Double Wedding Invitation

A fully static HTML, CSS and vanilla JavaScript wedding invitation website.

## Run
Simply open `index.html` in a browser.

## Add images
Place your images exactly here:
- `images/home/double-wedding-bg.jpg`
- `images/nikhil-sneha/hero.jpg` and `1.jpg` to `4.jpg`
- `images/nithya-ajay/hero.jpg` and `1.jpg` to `4.jpg`

## GitHub Pages
Upload all files while preserving the folder structure. In GitHub repository settings, enable **Pages** and deploy from the main branch/root folder.

All paths are relative, so the site works directly on GitHub Pages.
